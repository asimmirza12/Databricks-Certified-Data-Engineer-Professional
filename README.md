**Live course:** https://asimmirza12.github.io/Databricks-Certified-Data-Engineer-Professional/

A free course for people who are new to data engineering **and** new to Databricks. It starts from zero (what data
engineering is, files vs tables, Spark, Delta Lake, Unity Catalog) and then walks through every section of the
Data Engineer Professional exam guide, one small concept per lesson.

Every lesson has a plain-English explanation with an everyday analogy, an animated diagram, a live demo you can click,
commented code, "what if I change this?" tables, real-life scenarios, exam traps, a short quiz and links to the official docs.
Progress is saved in your browser only.

- Course plan and status: [OUTLINE.md](OUTLINE.md)
- Rules for contributors (and AI sessions): [CLAUDE.md](CLAUDE.md)

Plain HTML, CSS and JavaScript. No build step. To run locally:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
